Plagx Draft Preflight for Word

A free Microsoft Word add-in by Plagiarism Checker X. Check a draft before you submit it: word count and reading time, in-text citations against the reference list (APA or MLA), punctuation and basic grammar. Click an issue to find it in the document.

  • Checks run in the add-in, in your browser: nothing is stored or sent anywhere.
  • Reads the document only when you click Check draft; never changes your text.
  • Suggestions only: it does not detect plagiarism or AI-generated text.

Use

  1. Install Plagx Draft Preflight from Microsoft Marketplace (Word → Home → Add-ins).
  2. Click Home → Check draft.
  3. Choose the whole document or selected text, set word limits and citation style, and click Check draft.

Use a heading style (Heading 1–6 or Title) for your References or Works Cited heading, with each reference in its own paragraph.
